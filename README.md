# telegram-bot-downloads

Телеграм-бот, который скачивает видео из YouTube, TikTok и Instagram по ссылке,
умеет конвертировать видео в MP3, обрезать по времени и переименовывать
(артист + название).

## Стек

- Python 3.12+ / [aiogram 3](https://docs.aiogram.dev/)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — скачивание видео
- ffmpeg — конвертация в MP3, обрезка, теги

## Установка

1. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Убедись, что `ffmpeg` доступен в PATH:

   ```bash
   ffmpeg -version
   ```

3. Получи токен бота у [@BotFather](https://t.me/BotFather) и скопируй `.env.example` в `.env`:

   ```bash
   cp .env.example .env
   ```

   Впиши токен в `.env`:

   ```
   BOT_TOKEN=123456:ABC-твой-токен
   ```

4. Запусти бота:

   ```bash
   python bot.py
   ```

## Как пользоваться

1. Пришли боту ссылку на видео (YouTube / TikTok / Instagram).
2. После скачивания под видео появятся кнопки:
   - **🎵 В MP3** — конвертирует последний файл в аудио.
   - **✂️ Обрезать** — попросит диапазон времени вида `00:10-00:40`.
   - **✏️ Переименовать** — попросит `Артист - Название`, проставит теги и переименует файл.
3. Действия можно комбинировать друг за другом (скачал → обрезал → в MP3 → переименовал).

## Ограничения

- Telegram не позволяет боту отправлять файлы больше **50 МБ** — по умолчанию видео
  скачивается не выше 720p, чтобы обычно укладываться в лимит.
- Бот должен быть запущен постоянно (например, на этом ПК или на бесплатной VM
  вроде Oracle Cloud Free Tier), иначе он не будет отвечать.

## Деплой

Бот — обычный процесс на long polling, поэтому подходит любой хостинг, где можно
держать процесс включённым 24/7 и поставить ffmpeg:

- **Локально** — просто держать `python bot.py` запущенным.
- **Oracle Cloud Free Tier** — бесплатная VM навсегда, полный контроль над
  зависимостями (apt install ffmpeg, systemd-сервис для автозапуска).

Бесплатные тиры Railway/Render/Fly.io для постоянно работающих ботов сейчас сильно
урезаны и не гарантируют бесплатный 24/7 аптайм.
